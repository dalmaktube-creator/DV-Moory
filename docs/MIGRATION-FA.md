# مهاجرت به سرور جدید

برای امنیت، Copy کامل `/srv/moory` توصیه نمی‌شود.

## روش توصیه‌شده

1. Bridge را از GitHub روی سرور جدید Clone و نصب کنید.
2. GitHub App private key را امن انتقال دهید یا کلید جدید بسازید.
3. برای سرور جدید Deploy Keyهای تازه تولید و به Repositoryها اضافه کنید.
4. پروژه‌ها را Clone کنید.
5. DNS را تغییر دهید.
6. Bearer Token تازه بسازید و اتصال Notion را دوباره ثبت کنید.
7. پس از تست، دسترسی‌های سرور قدیمی را Revoke کنید.

این روش از انتقال تصادفی Token، SSH key یا فایل حساس جلوگیری می‌کند.
